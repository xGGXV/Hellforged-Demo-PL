# Hellforged Demo – Spolszczenie PL

Nieoficjalne polskie tłumaczenie gry Hellforged Demo.

## Aktualna wersja
v16.6 Public Beta 1.1

## Instalacja
1. Pobierz spolszczenie z zakładki Releases.
2. Wypakuj do folderu gry.
3. Uruchom ZAINSTALUJ_POLSKI.cmd.
4. W grze wybierz język Deutsch.
